# Мультиязычность сайта

Страницы собираются из шаблонов, а не правятся руками в трёх копиях.

```
tpl/*.html        шаблоны: разметка с маркерами {{ключ}}
i18n/ru.json      русские строки — источник правды
i18n/en.json      английские
i18n/es.json      испанские
i18n/parts/       черновики перевода по частям (из них собраны en/es)
```

## Пересобрать сайт

```bash
python3 bin/i18n_build.py          # все три языка
python3 bin/i18n_build.py es       # только испанский
```

Русская версия ложится в корень, остальные — в `en/` и `es/`.

## Поправить текст

1. Найти ключ в `i18n/ru.json` по русской фразе.
2. Поправить его же в `en.json` и `es.json`.
3. Пересобрать.

Строку, оставшуюся без перевода, сборщик подставит по-русски и скажет об этом.

## Что делает сборщик сам

- `{{#3801}}` — разделитель тысяч по языку: `3 801` / `3,801` / `3.801`
- дробь в разметке для испанского: `21.2%` → `21,2%` (даты и тысячи не трогает)
- подписи осей: `1000%` → `1,000%` / `1.000%`, годы не задевает
- на английской странице не выводит перевод эпиграфа — там оригинал Франклина

## Если менялась разметка страниц

`bin/i18n_extract.py` заново разбирает HTML на шаблон и словарь. Запускать
на чистых страницах, а не на собранных, иначе служебные вставки попадут
в словарь:

```bash
python3 bin/i18n_extract.py /путь/к/чистым/html
```

После этого ключи перенумеруются — переводы придётся связать заново
по совпадению русского текста.
