# Тревоги в Телеграм — как подключить

Сторож `bin/tg_watch.py` ходит внутри задания «Пульс счёта» каждый час
и пишет в Телеграм, когда что-то случилось. Чтобы он заговорил, нужны
два секрета репозитория: `TG_TOKEN` и `TG_CHAT`.

## 1. Завести бота

1. В Телеграме найти **@BotFather** (у него синяя галочка) и нажать «Запустить».
2. Отправить `/newbot`.
3. На вопрос об имени — любое, например `w2w сторож`. Можно с пробелами и по-русски.
4. На вопрос об username — уникальное, обязательно оканчивается на `bot`,
   например `w2w_watch_bot`. Занято — попросит другое.
5. В ответ придёт строка вида `8123456789:AAF3k…` — это **токен**, пароль от бота.
   Никому не показывать, в переписку не вставлять.

## 2. Написать боту первым

Бот не может начать диалог сам. В сообщении BotFather есть ссылка
`t.me/<имя_бота>` — открыть её и нажать «Запустить».

## 3. Узнать свой chat_id

Быстро: найти **@userinfobot**, нажать «Запустить» — он ответит `Id: 123456789`.
Для личных сообщений это и есть chat_id.

Надёжно: открыть в браузере (слово `bot` слитно с токеном)

    https://api.telegram.org/bot<ТОКЕН>/getUpdates

и найти в ответе `"chat":{"id":123456789,`. Если ответ `{"ok":true,"result":[]}` —
значит боту ещё не отправлен `/start`, вернуться к шагу 2.

## 4. Положить секреты в репозиторий

1. Открыть https://github.com/w2w-portfolio/w2w-portfolio.github.io
2. **Settings** → слева **Secrets and variables** → **Actions**.
3. **New repository secret**: Name `TG_TOKEN`, Secret — токен. **Add secret**.
4. Ещё раз: Name `TG_CHAT`, Secret — число из шага 3. **Add secret**.

В списке должно остаться два секрета. Посмотреть их значения нельзя
даже владельцу — только перезаписать.

## 5. Проверить связь

**Actions** → слева **Пульс счёта** → справа **Run workflow** → поставить
галочку «Проверить связь с Телеграмом» → зелёная **Run workflow**.
Через минуту в Телеграм придёт «Проверка связи: сторож w2w на месте.»

Не пришло — проверить: имена секретов точно `TG_TOKEN` и `TG_CHAT`,
боту отправлен `/start`, chat_id записан числом без кавычек и пробелов.

## Что будет приходить

* 🔕 наблюдатель молчит дольше двух часов — и ✅ когда данные снова пошли;
* 🟡🔴 сменился уровень риска по просадке (пороги 25 / 36 / 44);
* 📊 закрылись новые сделки — сводкой, а не по одной.

Повторов не будет: сторож помнит прошлое состояние в `data/alerts.json`
и пишет только при изменении.

## Если токен засветился

В @BotFather: `/revoke` → выбрать бота → он выдаст новый токен.
Старый сразу перестаёт работать. После этого перезаписать `TG_TOKEN`
в секретах репозитория.

## В канал вместо лички

chat_id канала выглядит как `-1001234567890`, и бота нужно добавить
в канал администратором с правом публикации. Для тревог личка удобнее:
они не мешаются с постами и приходят с уведомлением.
